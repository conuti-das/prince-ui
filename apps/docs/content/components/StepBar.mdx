# StepBar

Die **Stufenleiste** zeigt, wo ein Objekt auf seinem Weg steht – etwa ein Massenauftrag (angelegt → freigegeben → läuft →
abgeschlossen) oder ein Änderungspaket (angelegt → getestet → freigegeben → transportiert). Ohne `onSelect` reine Anzeige,
keine Leitfarbe (Regelwerk „Aktion, Hilfsaktion, Navigation, Ansicht“). Vorlage ist der Lagekopf des Massenauftrags in E.

## Verwendung

- Im Kopf des Objekts unter Titel und Zustand, eine Zeile; bei schmaler Fläche brechen ganze Stufen um.
- Je Stufe Nummer oder Zeichen, Name, optional eine zweite Zeile (Datum, Person, Zahl) und der Zustand **als Text** – Farbe allein trägt nie die Bedeutung.
- Genau eine Stufe ist `current`; sie trägt `aria-current="step"`.
- Abweichende Zustandstexte („überfällig“) über `stateLabel` je Stufe, übersetzte Texte über `stateLabels`.

<DoDont kind="do">Zustand „mit Problem“ an der Stufe, die hängt – mit Zeichen und Text.</DoDont>
<DoDont kind="dont">Knöpfe in die Stufenleiste setzen; Aktionen gehören in die Aktionsleiste im Kopf.</DoDont>

<Example code={`<StepBar aria-label="Stufen" density="compact" steps={[
  { id: 'a', label: 'Angelegt', state: 'done' },

Als Schrittleiste eines Assistenten: mit `onSelect` wird jede Stufe ein Knopf. Die Prüfung vor dem Wechsel macht die Anwendung in `onSelect`; Befunde am Schritt zeigt `state: 'problem'` mit `stateLabel`, noch nicht erreichbare Schritte tragen `isDisabled`.

<Example code={`<StepBar aria-label="Schritte: Mandant anlegen" onSelect={(id) => console.log(id)} steps={[
  { id: 'stamm', label: 'Stammdaten', state: 'done' },
  { id: 'rollen', label: 'Rollen', state: 'problem', stateLabel: '2 Befunde' },
  { id: 'kanal', label: 'Kanäle', state: 'current' },
  { id: 'pruefen', label: 'Prüfen', state: 'upcoming', isDisabled: true },
]} />`} />

## Accessibility

Eine geordnete Liste (`<ol>`) mit Namen (`aria-label`). Nummer und Zeichen sind dekorativ (`aria-hidden`); die Reihenfolge
kommt aus der Liste, der Zustand aus dem Text. Die aktuelle Stufe trägt `aria-current="step"`. Mit `onSelect` sind die Stufen Knöpfe in der Liste (Tab, Enter/Leertaste); `aria-current` sitzt dann am Knopf.
